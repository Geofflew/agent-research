# Style: caveman ultra

For `outputs/`, log lines, results notes, decisions. Not for `thesis.md` claims (those need full sentences for the judge).

- Max compression. Drop articles, filler, hedges, pleasantries.
- Fragments fine. One idea per line.
- Numbers, names, dates. No adjectives unless load-bearing.
- No framing, no intro, no summary at end.
- Quotes verbatim, tagged `— who, where`.
- Status tags inline: `[seed]` `[weak]` `[strong]` `[inference]`.

Example:
```
L2 verification: no auditor reliance case found. PCAOB AS 1105 silent on agents. [strong]
Nearest: TAR validation studies, legal. Judge accepted 2012 (Da Silva Moore). [strong]
Implication: finance L2 needs same: validation study vs human baseline. [inference]
```
