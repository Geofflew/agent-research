# Microsoft Foundry Models Lifecycle and Support Policy

URL: https://learn.microsoft.com/en-us/azure/ai-services/openai/concepts/model-retirements
Type: vendor
Read in session: 0006B

Summary: Microsoft force-upgrades Standard-type deployments to a replacement model when a version retires, region by region, on a published schedule; provisioned deployments are not auto-upgraded. Preview deployments get at least 30 days' notice of force-upgrade. This is the clearest case of the underlying model changing under the customer.

Quotes:
- "Microsoft manages automatic upgrades when a model version is retired" — Microsoft Learn, Automatic upgrades
- "Provisioned deployments are not auto-upgraded. Provisioned customers must manually migrate to the replacement model." — Microsoft Learn, Automatic upgrades
- "existing preview deployments are force-upgraded to a newer preview version. Customers get at least 30 days notice" — Microsoft Learn, preview lifecycle
- "If a model is found to have compliance or security issues, Microsoft reserves the right to invoke an emergency retirement with shortened notice." — Microsoft Learn, emergency retirements
