# Industrial Funding Group loan and security agreement with 1847 ICU Holdings (Feb 2023): view-only system access alongside audited annuals

URL: https://www.lawinsider.com/contracts/9zSIcHrd9ZK
Type: primary
Read in session: 0008B

Summary: Executed asset-based loan and security agreement (Exhibit 10.8, Industrial Funding Group, Inc. as lender; 1847 ICU Holdings / ICU Eyewear as borrowers, Feb 9, 2023, via Law Insider copy). The lender gets real-time view-only accounts to the borrower's banking, accounting and inventory systems as a closing condition (6.13) and a continuing covenant (9.18), plus API documentation. This is added on top of, not in place of, audited annual statements and monthly/quarterly unaudited statements. Counter-instance to the "data replaces audit" premise. Lender still charges up to $1000 per person per day for field audits. SEC.gov itself returns 403 to the scorer user agent, so the Law Insider copy is used.

Quotes:
- "Borrower shall provide Lender with real time view-only user accounts to Borrowers banking, accounting and inventory systems" — Section 6.13, closing condition
- "and to provide Lender with application programming interface documentation upon request" — Section 9.18 View-Only Access, continuing covenant
- "audited by an outside accounting firm acceptable to" — Schedule Section 7(b)(i), Annual Financial Statements, due within 90 days of fiscal year end
- "Up to $1000 per person, per day, plus out-of-pocket expenses, for not more than two (2) audits during each 12-month period" — Loan Agreement Schedule, Audit Expenses
