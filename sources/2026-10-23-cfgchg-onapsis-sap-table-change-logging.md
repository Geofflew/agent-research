# The Value of Table Change Logging For SAP Customizing Data (Onapsis)

URL: https://onapsis.com/blog/value-table-change-logging-sap-customizing-data/
Type: vendor
Read in session: 0006C

Summary: Security vendor on SAP table change logging for customizing (config) tables: goals are unauthorized-change detection and audit rules; default off until S/4HANA, then on by default; logging scope to be agreed with the audit organization.

Quotes:
- "Identification of unauthorized changes Fulfillment of legal requirements and audit rules" — Onapsis, goals of Table Change Logging
- "Starting with SAP S/4HANA 2021 it is enabled by default." — Onapsis
- "The default value of that parameter is OFF (Table Change Logging is disabled)." — Onapsis, rec/client
- "Changes to customizing tables can either be applied locally on the system or via transport requests from external systems." — Onapsis
- "The detailed definition of the logging relevance of tables must take place in consultation with your audit organization." — Onapsis
