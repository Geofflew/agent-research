# IESBA Code: Technology-related Revisions (final pronouncement text)

URL: https://www.pibr.org.pl/assets/meta/7077,IESBA_Technology_related_Revisions_to_the_Code_final.pdf
Type: standard
Read in session: 0003F

Summary: Clean and marked-up text of the IESBA technology revisions (approved April 2023, effective 15 Dec 2024), hosted as a PDF mirror by the Polish chamber PIBR. Adds automation bias to the named biases (120.12 A2), and R220.8 requires accountants who use technology output to exercise professional judgment on reliance. The Code never says judgments must be made by a human; it places the duty on the "professional accountant" and, for audit clients, on client management (R400.16, R606.3). The boundary is left to the entity: management decisions must be made by "a competent individual".

Quotes:
- "Automation bias, which is a tendency to favor output generated from automated systems," — IESBA Code 120.12 A2
- "such output is reliable or fit for purpose." — IESBA Code 120.12 A2, completing the automation bias definition
- "R220.8     A professional accountant who intends to use the output of technology, whether that" — IESBA Code R220.8 (professional judgment required on reliance)
- "technology was developed internally or provided by third parties, shall exercise professional" — IESBA Code R220.8
- "R400.15     A firm or a network firm shall not assume a management responsibility for an audit client." — IESBA Code R400.15

- "(b)   The client, through a competent individual (or individuals), preferably within senior" — IESBA Code R606.3(b), IT systems services to audit clients
