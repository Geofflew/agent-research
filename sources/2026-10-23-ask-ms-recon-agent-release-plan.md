# Microsoft release plan: Use agents for recommended actions on Account reconciliation agent workspace

URL: https://learn.microsoft.com/en-us/dynamics365/release-plan/2025wave1/finance-supply-chain/dynamics365-finance/use-agents-recommended-actions-account-reconciliation-agent-workspace
Type: vendor
Read in session: 0007C

Summary: Microsoft's own roadmap statement. Copilot notifies the finance team of a subledger-to-GL difference, offers options, and "eventually" resolves it. The first preview had no agent recommendations; the second added them. Auto-resolution is stated as a longer-term vision, so today the person decides.

Quotes:
- "Use Copilot to notify you of a difference between the subledger and the general ledger, provide options for how to resolve the issue, and eventually resolve the issue on your behalf" — Microsoft release plan, business value
- "proactively notifies the finance team of any reconciliation issues" — Microsoft release plan, feature details
- "doesn't include recommendations from the Account reconciliation agent for how to address exceptions" — Microsoft release plan, on the first public preview
- "Copilot learns from the solutions of the past and moves toward automatic resolution to any reconciliation issues (longer-term vision)" — Microsoft release plan
- "All actions taken by Copilot are tracked with an audit trail" — Microsoft release plan
