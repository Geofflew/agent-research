# Oracle Financial Consolidation and Close: Task Manager tutorial

URL: https://docs.oracle.com/en/cloud/saas/financial-consolidation-cloud/fcc-tutorial-task-manager/index.html
Type: vendor
Read in session: 0008B

Summary: Oracle describes Task Manager as automating the close with status tracking and email notices for delinquencies. A Pending task stays blocked until its predecessor closes even once its own start date arrives; parent task dates are rolled up from children. Notification is for delinquency and status change; no documented automatic re-dating of successors.

Quotes:
- "Pending tasks cannot open until their predecessor task closes, even if their start date is reached." — Oracle tutorial, Gantt view section
- "Notify users by e-mail for delinquencies, due dates, status changes." — Oracle tutorial, Background
- "interdependent activities of a business process" — Oracle tutorial, Background
- "The start date data of the parent task is the earliest start date of its child tasks, and the end date for the parent task is the latest end date of its child tasks." — Oracle tutorial
