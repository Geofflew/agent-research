# Sage Intacct AI Gateway (Sage product page)

URL: https://r.jina.ai/https://www.sage.com/en-hk/sage-business-cloud/intacct/product-capabilities/platform/ai-gateway/
Type: vendor
Read in session: 0008B

Summary: Sage page (direct fetch returns 403; read via r.jina.ai) positions the Intacct MCP Server as a connection layer for external AI tools, separate from Sage Copilot, the embedded AI that does AP processing and close tracking. It says AI models can "query and use" data under role-based permissions; it does not say read-only. Contrast is built in: embedded Copilot acts in workflows, outside tools get a governed gateway.

Quotes:
- "This approach allows AI models to query and use Sage Intacct data while maintaining governance and control." — Sage, AI Gateway FAQ
- "Sage Copilot is the embedded AI experience built into Sage Intacct." — Sage, AI Gateway vs Copilot FAQ
- "automating everyday tasks like accounts payable processing, tracking close activities, spotting errors in your numbers" — Sage, describing Copilot
- "Control how AI applications interact with Sage Intacct using role‑based permissions and built‑in governance." — Sage, AI Gateway page
