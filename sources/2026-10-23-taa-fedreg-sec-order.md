# SEC order approving PCAOB technology-assisted analysis amendments (Federal Register, 23 August 2024)

URL: https://www.govinfo.gov/content/pkg/FR-2024-08-23/html/2024-18986.htm
Type: primary
Read in session: 0006A

Summary: SEC approval order File PCAOB-2024-03 for AS1105/AS2301 amendments. Effective FY start on/after 2025-12-15. SEC: benefit also reaches engagements where auditors reluctant due to noncompliance risk. Regulatory uncertainty can be fixed by clarity.

Quotes:
- "This order approves the Amendments, which we find to be consistent with the requirements of Title I of SOX" — SEC, order approving File No. PCAOB-2024-03
- "The Amendments will be effective for audits of financial statements for fiscal years beginning on or after December 15, 2025" — SEC, order, Applicability and Effective Date
- "engagements where auditors have been previously reluctant to use technology- assisted analysis because of the risk of noncompliance" — SEC, order, economic analysis
- "PCAOB research indicates that some auditors may be reluctant to implement new technologies due to perceived regulatory uncertainty, which can be addressed through the clarity provided in the Amendments" — SEC, order, economic analysis
- "Specify auditor responsibilities when identifying items that require further investigation when performing tests of details" — SEC, order, description of Amendments
- "if the auditor uses an audit procedure for more than one purpose" — SEC, order, description of Amendments
