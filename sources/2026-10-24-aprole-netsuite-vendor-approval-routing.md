# Vendor approval in Payment Automation (NetSuite)

URL: https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_1006112830.html
Type: vendor
Read in session: 0007C

Summary: Changes to vendor bank details route to approval; vendor locked Pending Approval; modifier cannot approve own change.

Quotes:
- "New vendor records or changes to vendor records and vendor bank records go through approval routing." — Oracle NetSuite Help, Managing vendors
- "Pending Approval - you can't submit payments for processing or edit the vendor record." — Oracle NetSuite Help, AP Automation Status
- "The user who modified the vendor cannot approve the same vendor record." — Oracle NetSuite Help, Approving Vendors
- "Changes to standard and custom fields don't trigger vendor approval." — Oracle NetSuite Help, Vendor Approval Routing
