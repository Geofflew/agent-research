# Fieldguide, How Continuous Monitoring Reduces Audit Scope

URL: https://www.fieldguide.io/resource-articles/continuous-monitoring-audit-scope-client-controls
Type: vendor
Read in session: 0005B

Summary: Audit-software vendor blog, not standard text. Claims strong client continuous monitoring shrinks auditor retesting; leans on ISACA three-lines guidance. PCAOB 2024 inspections: no named CM deficiency, but AS 2201 control-testing failures are proxies. Engagement shifts from testing transactions to testing the monitoring infrastructure. Reliance is a firm-side choice, no PCAOB rule granting it. Treat as marketing.
