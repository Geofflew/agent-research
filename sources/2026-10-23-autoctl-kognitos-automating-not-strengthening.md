# Internal Controls: Automating a Control Is Not Strengthening It (Kognitos)

URL: https://www.kognitos.com/blog/internal-controls/
Type: vendor
Read in session: 0004

Summary: Vendor blog (deterministic-AI seller), 2026. Says manual controls need sampling; automated control shown once + unchanged supports reliance; benchmarking needs effective ITGC change mgmt. Then limits it: premise is same output from same input and detectable change; fails for probabilistic model-based controls. Cuts both ways on C3. Claims about amended PCAOB standard effective FY from 15 Dec 2026 unverified here.

Quotes:
- "if it executes the same logic every time, then demonstrating that it worked once, and that it did not change, goes a long way toward demonstrating that it worked throughout." — Kognitos
- "benchmarking applies when the it general controls are effective, particularly change management." — Kognitos
- "the control produces the same output from the same input, and you can tell when it has changed." — Kognitos, stated assumption behind benchmarking
- "a model-based control may produce different outputs from equivalent inputs" — Kognitos, on AI-based controls
