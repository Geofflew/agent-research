# Sovos: Consulting CFDI Cancelation (accept/reject web service)

URL: https://go.reachcore.com/docs/Articulos/AceptacionRechazo_EN
Type: vendor
Read in session: 0008B

Summary: PAC (Sovos) SOAP documentation for the SAT acceptance/rejection flow. A receiver's system can accept or reject cancellation requests programmatically through a PAC web service, signed with the receiver's CSD, so ERPs can automate responses.

Quotes:
- "This service allows the Receiver to accept or reject a receipt cancelation request." — Sovos docs
- "This method requires the signature of the requisition with the Receiver’s CSD." — Sovos docs, ProcesaPeticion
- "The only valued permitted are Aceptacion (no accent in this Spanish word) or Rechazo" — Sovos docs, Respuesta field
- "Accept or Reject the cancelation with a signature of origin." — Sovos docs, ProcesaPeticionFirmada
