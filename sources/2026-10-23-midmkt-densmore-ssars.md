# SSARS: audit vs review vs compilation (Densmore CPA)

URL: https://www.densmorecpa.com/blog/technical-spotlight-how-to-compare-engagements-audit-vs-review-vs-compilation/
Type: secondary
Read in session: 0005B

Summary: CPA firm explainer. Review = mainly inquiry + analytics on internal info. Compilation = no testing. Lender named as typical external user wanting assurance.

Quotes:
- "You usually see this when a user, often an external one like a lender, wants some level of assurance over financial statements." — Densmore CPA blog
- "Review: Mainly inquiry and analytical procedures, using internal information; limited testing if needed Compilation: No testing, just organizes financial information provided by management" — Densmore CPA blog
