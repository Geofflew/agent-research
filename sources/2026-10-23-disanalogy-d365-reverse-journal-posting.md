# Reverse journal posting (Dynamics 365 Finance)

URL: https://learn.microsoft.com/en-us/dynamics365/finance/general-ledger/reverse-journal-posting
Type: vendor
Read in session: 0006A

Summary: Posted journal corrected by reversal entry, whole journal or voucher. Reversal needs new date if original period closed. Exception: vendor payments not reversible this way, separate flow. Supports cheap reversal; payment release is the exception.

Quotes:
- "You can reverse journal lines individually." — Microsoft Learn, Reversing journals
- "In some cases, the period of the original transaction might be closed, and you must enter a new transaction date for the reversal." — Microsoft Learn, Reversing journals
- "Transactions can be reversed only if they meet the business rules for reversing them." — Microsoft Learn, voucher reversal section
- "Vendor payments can't be reversed by using the capability that's described in this article." — Microsoft Learn, voucher reversal section
