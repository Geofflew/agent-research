# Business Central: Set up vendor bank accounts

URL: https://learn.microsoft.com/en-us/dynamics365/business-central/purchasing-how-set-up-vendors-bank-accounts
Type: vendor
Read in session: 0008B

Summary: Vendor bank accounts are a separate record (Vendor Bank Account Card/List) reached from the vendor card. Microsoft flags the fields as sensitive and ships a Vendor Bank Account Approval Workflow template so new accounts need review.

Quotes:
- "Some fields on the vendor bank account contain sensitive business data" — Microsoft Learn warning box
- "You can set up an approval workflow that requires people to submit new vendor bank accounts for review." — Microsoft Learn
- "Business Central provides a workflow template named Vendor Bank Account Approval Workflow" — Microsoft Learn
