# LangGraph docs: Interrupts

URL: https://docs.langchain.com/oss/python/langgraph/interrupts
Type: vendor
Read in session: 0009B

Summary: Official LangGraph docs on human-in-the-loop. When a step needs external input the graph pauses and waits; it does not replan around the missing input. This is the orchestrator analogue of a gated close task waiting on a person.

Quotes:
- "Interrupts allow you to pause graph execution at specific points and wait for external input before continuing." — LangGraph docs
- "waits indefinitely until you resume execution with a response" — LangGraph docs (surrounding text: "Graph waits indefinitely until you resume execution with a response")
- "saves the graph state using its persistence layer" — LangGraph docs
