# Fedwire Funds Service ISO 20022 Format FAQ (Federal Reserve Financial Services)

URL: https://www.frbservices.org/resources/financial-services/wires/fedwire-services-frequently-asked-questions/fedwire-service-iso-20022-faq/format-faq/
Type: primary
Read in session: 0007C

Summary: Fed operator FAQ post go-live. ISO 20022 live on Fedwire 14 Jul 2025 (single-day, FAIM replaced). End-to-End ID mandatory so creditor can reconcile. Free-text remittance misuse already hurting receivers. Hybrid address mandatory 16 Nov 2026. CPMI cross-border data model end 2027. Does not itself describe structured remittance (remt/ERI) fields.
