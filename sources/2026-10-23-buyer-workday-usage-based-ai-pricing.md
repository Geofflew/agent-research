# Workday blog: Journey to Usage-Based AI Pricing (finance leader)

URL: https://blog.workday.com/en-us/usage-based-ai-pricing.html
Type: vendor
Read in session: 0005C

Summary: Workday finance exec: seat/employee pricing shifting to hybrid consumption + outcomes. Flex Credits metered on completed action in production. Workday built own Financial Close Agent instead of multimillion external spend; frames buyer test as cost avoidance and headcount managed as revenue scales. Buyer = finance leader / CFO org, not controller.

Quotes:
- "the traditional per-seat licensing model is shifting toward a hybrid model driven by consumption and tangible outcomes" — Tim Garippa, Workday blog
- "AI agents are metered when they complete an action, not every time a query is made or a token is consumed." — Workday blog
- "Before Workday began building the Financial Close Agent, we initially considered a multimillion-dollar external software spend." — Workday blog, Customer Zero
- "Are we actively re-engineering the organization to realize cost avoidance and manage headcounts sustainably as revenue scales?" — Workday blog, finance test for AI deployment
- "Moving away from a fixed, predictable G&A cost structure to a variable consumption model introduces significant forecasting hurdles." — Workday blog
