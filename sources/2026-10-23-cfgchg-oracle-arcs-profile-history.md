Type: vendor

Summary: Oracle docs: auto-reconciliation tolerances (percent and fixed amount) are set per profile; a History tab logs profile changes. Docs do not say old/new tolerance values are captured.

- "the tolerance value is specified on the profile" — Oracle docs
- "Enter the Match Balance Threshold (Percent) as a whole number between 1 and 100." — Oracle docs
