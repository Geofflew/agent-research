# NetSuite: Enabling Web Services Concurrent Users with SuiteCloud Plus

URL: https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_N3448861.html
Type: vendor
Read in session: 0008C

Summary: Oracle NetSuite help: API integration capacity is metered as concurrent requests per account, raised by buying SuiteCloud Plus licenses. Web services and RESTlet requests share one account-level limit; the limit is lenient.

Quotes:
- "each suitecloud plus license increases the account base limit for concurrent web services requests by 10" — source page
- "web services and restlet concurrency is also governed per account" — source page
- "the account limit is lenient, and it is possible to temporarily exceed the limit" — source page
