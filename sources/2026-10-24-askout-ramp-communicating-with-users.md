# Ramp help: communicating with other users (missing-item reminders)

URL: https://support.ramp.com/communicating-with-other-users-on-ramp
Type: vendor
Read in session: 0008B

Summary: Reminders to employees for missing receipts/memos are triggered by an admin or manager button, use a fixed template, and cannot carry a personal message. Separately Ramp auto-sends SMS/email/Slack/Teams messages to employees for missing items. Flagged transactions open an email thread between reviewer and cardholder.

Quotes:
- "These reminders use a standard Ramp notification template and cannot be customized with a personal message." — Ramp Help Center, Sending reminders for missing items
- "Employees receive an email listing the specific transactions that need attention." — Ramp Help Center
- "Ramp automatically notifies cardholders via SMS and email when they need to submit receipts or memos after a transaction." — Ramp Help Center, Submission policy reminders
- "Ramp sends direct messages to employees for transaction approvals, reimbursements, and missing items." — Ramp Help Center, Slack and Microsoft Teams
- "admins can request changes, which starts an email thread between the reviewer and the cardholder." — Ramp Help Center, Transaction flagging
- "Admins do not compose these messages" — Ramp Help Center, Other ways Ramp notifies employees
