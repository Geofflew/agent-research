# How to Use Ramp's Accruals Feature (Ramp Help Center)

URL: https://support.ramp.com/hc/en-us/articles/45051928397459-How-to-Use-Ramp-s-Accruals-Feature
Type: vendor
Read in session: 0006B

Summary: Product doc for Ramp's accrual agent. Accrual is built from unsynced card transactions and reviewed only by the accountant in a table; no step asks the cardholder or a budget owner anything. Missing receipts/memos/approvals are simply accrued; fixes are done by finance via GL dropdown.

Quotes:
- "book costs that are missing receipts, memos, or approvals so you can close on time." — How to Use Ramp's Accruals Feature (Ramp Help Center)
- "update your mapped accounting fields directly in the review table before you sync the accrual." — How to Use Ramp's Accruals Feature (Ramp Help Center)
- "ramp syncs an accrual journal entry only after a user selects sync accrual(s)" — How to Use Ramp's Accruals Feature (Ramp Help Center)
- "ramp does not provide a setting to disable accruals in accounting settings" — How to Use Ramp's Accruals Feature (Ramp Help Center)
