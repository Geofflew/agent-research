# Fieldguide: Field Agents for Request Analysis (help center)

URL: https://help.fieldguide.io/en/articles/12542698-field-agents-for-request-analysis
Type: vendor
Read in session: 0008B

Summary: Help article (Dec 2025) for an agent that runs automatically on every upload or deletion in a request, summarizes files, flags gaps and links files to sample items. Links behave like manual ones and can be overridden. Describes the analysis, not release to the auditor or any client-side drafting.

Quotes:
- "the Request Analysis Agent evaluates them, flags missing or incomplete information, and—when applicable—links files to sample items automatically." — Fieldguide Help Center
- "You do not need to manually start or refresh the agent—the system runs automatically." — Fieldguide Help Center
- "It flags missing, incomplete, or out-of-period information." — Fieldguide Help Center
- "You can override or adjust links manually at any time." — Fieldguide Help Center
- "When the agent links a file to a sample item, it works the same as if you had linked the file manually." — Fieldguide Help Center
