# AP2 (Agent Payments Protocol) docs: home page and mandates

URL: https://ap2-protocol.org/
Type: primary
Read in session: 0004

Summary: AP2 = open protocol, Google-led. Verifiable digital credentials chained into audit trail for human-present and human-not-present. Current docs (sub-pages agent_authorization, checkout_mandate, payment_mandate): Open mandate (constraints, agent-bound) vs Closed mandate (bound to one transaction); Checkout + Payment mandate types, not launch-era Intent/Cart/Payment. Payment mandate constraints include amount range, budget, allowed payees.

Quotes:
- "AP2 provides a non-repudiable, cryptographic audit trail for every transaction, aiding in dispute resolution and building confidence for all participants." — AP2 docs home, core principles
- "chained together to provide a complete, verifiable audit trail for both human-present and human-not-present transactions." — AP2 docs home, on VDCs
- "if a fraudulent or incorrect transaction occurs, who is accountable" — AP2 docs home, why a protocol is needed
- "trust in payments is anchored to deterministic, non-repudiable proof of intent from the user" — AP2 docs home, core principles
