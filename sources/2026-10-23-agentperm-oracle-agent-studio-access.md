# Oracle Fusion AI Agent Studio: access requirements (26B docs)

URL: https://docs.oracle.com/en/cloud/saas/fusion-ai/26b/aiaas/access-ai-agent-studio.html
Type: vendor
Read in session: 0004

Summary: Oracle 26B docs, modified 2026-05-28. Access to configure agents via predefined duty roles assigned to job roles, per product family (HCM, SCM, Procurement) plus Security Console permission groups. Role-gated build and monitor access, not an agent identity with decision-class write scope; no revocation, no amount cap. Finance family not listed in the quoted role list.

Quotes:
- "you can give access to ai agent studio by assigning predefined duty roles to job roles" — Oracle docs 26B, access requirements
- "you can give people access to configure ai agents in all or specific products" — Oracle docs 26B, access requirements
- "search for and add the read:generative ai workflow execution permission group" — Oracle docs 26B, assign permission group to view monitored agent records
