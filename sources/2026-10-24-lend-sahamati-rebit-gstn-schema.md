# Sahamati: ReBIT publishes GSTN data schema for the Account Aggregator framework (21 Jun 2023)

URL: https://sahamati.org.in/rebit-publishes-gstn-data-schema-for-the-account-aggregator-framework
Type: primary
Read in session: 0006B

Summary: Industry-alliance (Sahamati, RBI-recognised SRO) description of what GST data lenders get via AA: GSTR-1 (Table 4) and GSTR-3B completed returns for the last 18 months, plus profile data, released on taxpayer consent by the primary authorised signatory. Cites an MSME credit gap. Note: page dates the RBI notification to September 2022; the RBI circular itself is dated 23 Nov 2022.

Quotes:
- "Completed returns filed in the last 18 months for the following return types" — source page
- "Primary authorised signatory, whose mobile number is seeded in GSTN records, will provide consent to share GST data with any potential FIU." — Sahamati, key features of GSTN specs
- "only 15-20% of the MSMEs in India are estimated to have access to credit" — Sahamati citing experts
