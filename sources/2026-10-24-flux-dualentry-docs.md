# DualEntry docs: Flux Analysis (threshold, AI generate, activity log)

URL: https://docs.dualentry.com/accountants/reporting-analytics/flux-reporting
Type: vendor
Read in session: 0009C

Summary: Product docs (Beta). Four threshold types (percent, amount, either, both); flagged rows can require an explanation. AI generate drafts one line at a time from statistical pattern-matching on account history, shown as AI draft; reviewer Accepts (then edits) or Discards. Permanent activity log; rows re-flag if GL changes after explanation. No cited GL entries, no separate reviewer sign-off step.

Quotes:
- "Amount and percentage: Both limits must be exceeded for a line to be flagged." — DualEntry docs, Variance threshold
- "The Require explanation on flagged row switch controls whether flagged rows must have an explanation." — DualEntry docs, Variance threshold
- "Choose Accept to use it, then edit as needed, or Discard to drop it." — DualEntry docs, AI generate
- "AI generate is available line by line, not as a bulk operation." — DualEntry docs, AI generate
- "The current implementation uses statistical pattern-matching against account history." — DualEntry docs, AI generate
- "The activity log is permanent and cannot be deleted." — DualEntry docs, Activity log
- "DualEntry re-flags any row whose balance changed after you wrote an explanation, so you can confirm the explanation still holds." — DualEntry docs, Workflow step 5
