# Close the general ledger at period end (Dynamics 365 Finance)

URL: https://learn.microsoft.com/en-us/dynamics365/finance/general-ledger/close-general-ledger-at-period-end
Type: vendor
Read in session: 0006A

Summary: Period status = native posting gate. On hold blocks posting, can restrict to user group. Permanently closed irreversible, Microsoft says avoid. Close is the control point; open-period posting reversible.

Quotes:
- "Set ledger periods to On hold , so that no further posting occurs." — Microsoft Learn, period-end steps
- "You can also restrict a period to a specific user group while period-end activities are occurring, for better control." — Microsoft Learn, period-end steps
- "Don't set periods to Permanently closed , because you can't reopen a period that you closed." — Microsoft Learn, period-end steps
- "Verify that all journals are posted." — Microsoft Learn, period-end steps
