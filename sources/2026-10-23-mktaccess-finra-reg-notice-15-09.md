# FINRA Regulatory Notice 15-09 Effective supervision and control practices for algorithmic trading

URL: https://www.finra.org/rules-guidance/notices/15-09
Type: primary
Read in session: 0004

Summary: FINRA guidance Mar 2015. Effective practices across algo lifecycle: change mgmt, independent testing, segregated test env, pilot deploy, quick-disable, real-time monitoring. Ties to Rule 15c3-5.

Quotes:
- "implementing a development and change management process that tracks the development of new trading code or material changes to existing code" — FINRA Regulatory Notice 15-09
- "providing mechanisms by which the firm may quickly disable the algorithm or supporting platform with a minimal number of steps" — FINRA Regulatory Notice 15-09
- "where feasible, deploying new algorithmic strategies in a pilot phase of limited size, increasing only as results are confirmed" — FINRA Regulatory Notice 15-09
- "establishing a quality assurance process such that testing is performed independently of code development" — FINRA Regulatory Notice 15-09
