# FloQast Help: AI Transaction Matching (rules, review, auto sync)

URL: https://help.floqast.com/api/v2/help_center/en-us/articles/30344740630683.json
Type: vendor
Read in session: 0006A

Summary: FloQast Create AI Rule: user selects example match, FloQast drafts rule in natural language, user names/edits criteria, Save & Apply runs on remaining txns, saved per future period. Each match shows rule name. Edit rule removes and reapplies its matches. Rule is visible text; NL translated by AI pipeline into underlying logic.

Quotes:
- "FloQast will create a starting point for the rule based on the selected transactions." — FloQast help center article
- "Once you've named the rule and are satisfied with the wording and criteria, you can click Save & Apply to add the rule and match all of the remaining transactions that meet the rule criteria." — FloQast help center article
- "Once all of your rules are created, they will be saved and automatically available for each period going forward." — FloQast help center article
- "This will remove all matches associated with the rule and reapply the rule with the new criteria." — FloQast help center article
- "Your rule runs through the same AI pipeline as AI-suggested rules, which translates your natural language description into the underlying matching logic." — FloQast help center article
- "Each match will also display which Rule was used to create it, which can be filtered." — FloQast help center article
- "If you need to remove a match made by a rule, we recommend editing or deleting the rule within the rules drawer, which will remove all matches associated with those rules." — FloQast help center article
- "The Auto Sync & Apply Rules feature uses Autopilot to create a nightly job that automatically syncs and applies all rules across all accounts with open reconciliation periods." — FloQast help center article
