# PracTools nAuditMUS: Sample sizes for a Monetary Unit Sample in an audit

URL: https://search.r-project.org/CRAN/refmans/PracTools/html/nAuditMUS.html
Type: secondary
Read in session: 0006A

Summary: MUS = selection prob proportional to dollar size. Tolerable error set as dollar amount or pct. High-value items become certainties. Cites GAO FAM 480.21-.26. Sample size tied to tolerable dollar error not item count.

Quotes:
- "the sample will be selected with probabilities proportional to a measure of size (MOS)" — PracTools nAuditMUS doc
- "When the MOS of each record is a monetary unit, auditors refer to this as an monetary unit sampling or dollar unit sampling" — PracTools nAuditMUS doc
- "if the expected error or misstatement is 0, (i.e. exp.error = 0), then the sample size is computed using the hypergeometric distribution where the acceptable number of deviations is 0" — PracTools nAuditMUS doc
- "number.highval number of records that are high value (exceed the interval used for systematic sampling) and will be certainties in the sample" — PracTools nAuditMUS doc
- "the amount of error expressed as a value or a percentage that the auditor considers tolerable" — PracTools nAuditMUS doc
