# SBA Paycheck Protection Program page: forgiveness documentation by loan size

URL: https://www.sba.gov/funding-programs/loans/covid-19-relief-options/paycheck-protection-program
Type: standard
Read in session: 0009B

Summary: SBA page for the government-guaranteed PPP. Documentation burden tiers by loan size: loans of $150,000 and below use Form 3508S with no upfront documents (audit-on-request); larger loans must submit documents. A size threshold below which verification is deferred to after-the-fact review.

Quotes:
- "Form 3508S does not require borrowers to provide additional documentation upon forgiveness submission, but borrowers should be prepared to provide relevant documentation if requested as part of the loan review or audit processes." — SBA PPP page
- "do require a borrower to provide additional documentation upon forgiveness submission" — SBA PPP page, Form 3508 and 3508EZ for loans over $150,000
