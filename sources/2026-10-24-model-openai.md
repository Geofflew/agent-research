# OpenAI API Deprecations

URL: https://platform.openai.com/docs/deprecations
Type: vendor
Read in session: 0006B

Summary: OpenAI's deprecations page sets minimum retirement notice by model class (6 months GA, 3 months specialized variants, as little as 2 weeks for previews) and lists dated shutdowns, e.g. GPT-4o and GPT-4.1 on January 14, 2027. Notice is by email and on the page; the customer does not control timing.

Quotes:
- "Unless safety or compliance concerns require a faster timeline, we provide the following minimum notice periods before model retirement: generally available models: at least 6 months." — OpenAI, Model deprecation notice periods
- "preview models, identified by preview in the model name, may be retired with much shorter notice, such as 2 weeks." — OpenAI, notice periods
- "When we announce a model deprecation, we notify customers who are actively using the model by email and document the deprecation on this page." — OpenAI, notice periods
- "January 14, 2027 gpt-4o ( gpt-4o-2024-08-06 , gpt-4o-2024-11-20 ) gpt-6-luna" — OpenAI, shutdown table (gpt-4o shutdown date and replacement)
- "Fine-tuned versions of these models follow the same shutdown schedule as their underlying base models." — OpenAI, shutdown table note
