# Anthropic Model Deprecations

URL: https://docs.anthropic.com/en/docs/about-claude/model-deprecations
Type: vendor
Read in session: 0006B

Summary: Anthropic commits to at least 60 days' notice before retiring publicly released models, notified to customers with active deployments. Retired models fail on request. Partner platforms (Bedrock, Google-managed) set their own schedules, so dates can differ by channel.

Quotes:
- "Anthropic notifies customers with active deployments for models with upcoming retirements, providing at least 60 days' notice before model retirement for publicly released models." — Anthropic, Notifications
- "Retired: the model is no longer available for use. Requests to retired models fail." — Anthropic, lifecycle terms
- "claude-opus-4-1-20250805 retired june 5, 2026 august 5, 2026" — Anthropic, model table row (api name, state, deprecated date, retirement date)
- "partner-operated platforms, amazon bedrock and claude models on google cloud (google managed), set their own retirement schedules, so a model's lifecycle status and dates can differ." — Anthropic, overview
