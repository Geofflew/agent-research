# ISA (UK and Ireland) 402: using a Type 2 report as audit evidence

URL: https://www.charteredaccountants.ie/chariotindex/text/apb_isa_402_2010/28.html
Type: standard
Read in session: 0005B

Summary: ISA 402 application material (A31-A38). User auditor judges whether service auditor Type 2 report fits its assertions and period. Shared report may not cover user's assertions. Stale/short period = less evidence. CUECs = controls user must run itself. Exceptions in report feed user auditor risk assessment. Older 2010 UK/Ireland text; 10.html on same host holds para 17.

Quotes:
- "a type 2 report may be intended to satisfy the needs of several different user auditors; therefore tests of controls and results described in the service auditor's report may not be relevant to assertions that are significant in the user entity's financial statements" — ISA 402 para A31
- "the user auditor may conclude that the type 2 report offers less audit evidence if there is little overlap between the period covered by the type 2 report and the period for which the user auditor intends to rely on the report" — ISA 402 para A32
- "the user auditor may determine it is necessary to perform, or use another auditor to perform, tests of controls at the service organization" — ISA 402 para A32
- "the service may be designed with the assumption that the user entity will have controls in place for authorizing transactions before they are sent to the service organization for processing" — ISA 402 para A36, complementary user entity controls
- "exceptions noted by the service auditor or a modified opinion in the service auditor's type 2 report do not automatically mean that the service auditor's type 2 report will not be useful" — ISA 402 para A38
