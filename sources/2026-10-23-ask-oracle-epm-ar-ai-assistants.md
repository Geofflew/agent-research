# Oracle Cloud Readiness: Account Reconciliation AI Assistants (EPM, June 2026)

URL: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-jun26/26jun-epm-wn-f49598.htm
Type: vendor
Read in session: 0007C

Summary: Oracle's shipped "AI agent" for account reconciliation is a set of chat assistants a user or admin invokes. Users view a reconciliation and add or read comments; admins run jobs. No proactive ask, routing or task creation is described. Counterexample to agents that push work to people.

Quotes:
- "EPM assistants are importable assistants that integrate with Fusion AI Agent Studio to provide a chat-based experience" — Oracle readiness notes
- "Helps users interact with reconciliations, performing tasks such as viewing reconciliation details, adding comments to a reconciliation, and displaying comments" — Oracle readiness notes, Account Reconciliation Assistant for Users
- "enabling you to quickly find information and perform tasks through natural language interactions" — Oracle readiness notes, business benefit
