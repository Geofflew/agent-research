# Agenzia delle Entrate Circolare 13/E (2 July 2018): SdI rejection (scarto), 5-day resend, uniqueness check

URL: https://r.jina.ai/https://www.agenziaentrate.gov.it/portale/documents/20143/297470/Circolare+n+13+del+02+luglio+2018_Circolare_13_02072018.pdf/da0b0db7-64eb-ac7b-c925-4fdbc776279d
Type: primary
Read in session: 0008A

Summary: Binding tax-authority interpretation. SdI runs checks on each file; a rejected file's invoice is "non emessa", so the issuer may resend within 5 days, preferably with the same number and date. SdI's uniqueness check blocks any invoice already transmitted and processed; a booked-but-rejected invoice is reversed internally with no variation note sent to SdI. Rejection is the only reversible window; the notice arrives within 5 days.

Quotes:
- "il sdi, per ogni file della fattura elettronica o lotto di fatture elettroniche correttamente ricevuti, effettua successivi controlli del file stesso" — AdE Circolare 13/E 2018, quesito on rejection
- "si considera non emessa" — AdE Circolare 13/E 2018, on invoice in a file rejected by SdI
- "senza la trasmissione di alcuna nota di variazione al sdi" — AdE Circolare 13/E 2018, internal accounting reversal when rejected invoice was already booked
- "nuovamente inviata tramite sdi entro cinque giorni dalla notifica di scarto" — AdE Circolare 13/E 2018, resend window
- "al fine di intercettare ed impedire l'inoltro di un documento già trasmesso ed elaborato" — AdE Circolare 13/E 2018, purpose of SdI uniqueness checks
