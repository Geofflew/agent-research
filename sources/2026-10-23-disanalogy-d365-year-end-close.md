# Year-end close (Dynamics 365 Finance)

URL: https://learn.microsoft.com/en-us/dynamics365/finance/general-ledger/year-end-close
Type: vendor
Read in session: 0006A

Summary: On-hold periods reopenable for adjusting entries even after year-end run. Only permanently closed blocks adjustments. Microsoft: set that option No as best practice. Ledger error fixable post-close until hard lock.

Quotes:
- "When adjusting entries are identified, the on-hold periods can be reopened so that adjusting entries can be posted, even if the year-end close process has already been run." — Microsoft Learn, Ledger calendar step
- "Use this option carefully, because periods that have a permanently closed status can't be reopened." — Microsoft Learn, Set fiscal year status to permanently closed
- "Therefore, adjustments can't be posted to the fiscal year." — Microsoft Learn, Set fiscal year status to permanently closed
- "Each fiscal period for the fiscal year that's being closed can be set to On hold to prevent new transactions from being entered." — Microsoft Learn, Ledger calendar step
