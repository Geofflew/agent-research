# Quarterly Update: Preparation and Testing Recommendations Guide (Oracle Fusion Cloud)

URL: https://r.jina.ai/https://docs.oracle.com/en/cloud/saas/transportation/25c/otmpt/quarterly-update-preparation-and-testing-recommendations-guide.pdf
Type: vendor
Read in session: 0008C

Summary: Oracle vendor doc (Transportation/GTM module; same quarterly cadence as Fusion Cloud Applications). Updates are mandatory and cannot be rescheduled; test environments get them on the first Friday and production two weeks later on the third Friday. The customer builds its own test plan to validate its CURRENT configuration (integrations, key process flows by role, custom reports) and logs service requests before production. No SOX mapping; the timeline is a customer-side checklist.
