# PCAOB AS 2105: materiality and tolerable misstatement

URL: https://r.jina.ai/https://pcaobus.org/oversight/standards/auditing-standards/details/AS2105
Type: standard
Read in session: 0006A

Summary: Materiality set for FS as a whole, in dollars. Tolerable misstatement set below it so total uncorrected + undetected stays non-material. Item risk judged against aggregate, not per-item.

Quotes:
- "the auditor should establish a materiality level for the financial statements as a whole that is appropriate in light of the particular circumstances" — PCAOB AS 2105 para .06
- "the materiality level for the financial statements as a whole needs to be expressed as a specified amount" — PCAOB AS 2105 para .06
- "reduce to an appropriately low level the probability that the total of uncorrected and undetected misstatements would result in material misstatement of the financial statements" — PCAOB AS 2105 para .08
- "tolerable misstatement should be less than the materiality level for the financial statements as a whole" — PCAOB AS 2105 para .08
