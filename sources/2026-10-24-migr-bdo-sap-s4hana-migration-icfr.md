# BDO: SAP S/4HANA Migration (ICFR and system implementation controls)

URL: https://www.bdo.com/insights/assurance/sap-s-4-hana-migration
Type: vendor
Read in session: 0006B

Summary: BDO (audit firm, marketing-flavored advisory page, 30 Mar 2026). Says ECC mainstream support ends 2027, migrations take 18-36 months, and the external auditor tests management's system implementation and conversion controls; offers post-implementation vs real-time assessment. Implies migration creates its own control-testing scope; does not use the word baseline.

Quotes:
- "mainstream support for sap ecc ends in 2027" — BDO, Why migrate now
- "many ICFR and SOX controls rely on automated processes within SAP" — BDO, internal control risks
- "the BDO - as the external auditor - tests management's system implementation and conversion controls after the control activities have already taken place" — BDO, post implementation assessment
- "This approach does not allow for an opportunity to remediate findings prior to fiscal year-end." — BDO, post implementation assessment
- "performs an assessment of management's system implementation & conversion controls in real-time" — BDO, real-time system implementation assessment (RTSA)
- "identifies opportunities for the use of more effective and cost-efficient automated application controls" — BDO, RTSA
- "Total duration *18-36 months" — BDO, typical ECC to S/4HANA migration timelines table
- "public cloud implementations range from 9-12 months while private cloud implementations range from 12 - 18 months" — BDO, timeline note
