# SuiteApprovals Approval Workflow States (NetSuite Help)

URL: https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/section_0602080723.html
Type: vendor
Read in session: 0007A

Summary: Describes the SuiteApprovals workflow that runs approvals on supported records including journal entries. Validation starts only when a record is created or resubmitted through the UI; a note lists CSV import, script, web service and RESTlet as methods that are not routed. Second vendor page stating the same exclusion.

Quotes:
- "approval validation starts when you create or resubmit a record through the NetSuite user interface." — NetSuite Help, Approval Workflow States
- "transaction records created using the following methods aren't routed for approval" — NetSuite Help, Approval Workflow States (note; list: CSV import, Script, Web service, RESTlet)
