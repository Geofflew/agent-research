# Microsoft Learn: Financial period close workspace (Dynamics 365 Finance)

URL: https://learn.microsoft.com/en-us/dynamics365/finance/general-ledger/financial-period-close-workspace
Type: vendor
Read in session: 0007C

Summary: The non-agent baseline for what replaces the preparer's checklist: a template of recurring tasks, each with a named assignee and relative due date, generated per closing schedule. Users can be limited to seeing only their assigned tasks. Nothing on the page involves an agent filling or chasing tasks.

Quotes:
- "A closing task is a recurring work effort that you assign to an individual to complete as part of each closing process" — Microsoft Learn, Templates
- "In the template, you must define a relative due date for each closing task" — Microsoft Learn, Templates
- "The tasks from the template are then automatically generated" — Microsoft Learn, Closing schedules
- "you see either all tasks and statuses for a closing schedule, or just the tasks that are assigned to you" — Microsoft Learn, workspace overview
- "Users who have permissions to view only their assigned tasks can't add tasks to the task list, edit tasks, or remove tasks from the task list" — Microsoft Learn, Resources
