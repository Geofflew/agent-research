# Business Central: Set up Payables Agent (agent permission set)

URL: https://learn.microsoft.com/en-us/dynamics365/business-central/payables-agent-setup
Type: vendor
Read in session: 0007A

Summary: Payables Agent (vendor invoice intake) is a BC user account with a system permission set "Payables Ag. - Run" restricted to objects/fields/actions needed for vendor invoices. Customizable only via a copy. No payment or bank-account scope stated; the agent produces unposted invoices.

Quotes:
- "The Payables Agent has a user account in Business Central, similar to other users." — MS Learn, Manage agent's permissions to objects, data, and UI elements
- "By default, the Payables Agent has the Payables Ag. - Run permission set. This set restricts access to only the objects, data, and UI elements (such as pages, fields, and actions) necessary for processing vendor invoices." — MS Learn, same section
- "you can't modify the Payables Ag. - Run permission set directly, because it's a system permissions set." — MS Learn, same section
- "the feature doesn't introduce any new Payables Agent permission setup." — MS Learn, purchase order matching section (shows no extra scope for matching)
