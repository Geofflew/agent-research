# Stampli: Vendor bank change callback protocol

URL: https://www.stampli.com/resources/vendor-bank-change-callback-protocol/
Type: vendor
Read in session: 0005B

Summary: AP-automation vendor (Stampli) reference guide. Bank change = unverified until confirmed via trusted channel. Callback to number on file, second-person approval, pending-verification state before payment uses new account. Strongest control: portal-only changes.

Quotes:
- "Treat every bank-change request as unverified until you confirm it through a channel you already trust - never by replying to the email." — Stampli Finance Index
- "phone the vendor on a number already on file (not one supplied in the request)" — Stampli Finance Index
- "route the change through a second-person approval before any payment uses the new account" — Stampli Finance Index
- "A call-back protocol is a written rule that no banking change takes effect until someone independently phones the vendor and confirms it." — Stampli Finance Index
- "Yes, and it's the strongest single control" — Stampli Finance Index, on portal-only bank-change requests
