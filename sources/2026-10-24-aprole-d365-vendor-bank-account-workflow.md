# Vendor bank account workflow (Dynamics 365 Finance)

URL: https://learn.microsoft.com/en-us/dynamics365/finance/accounts-payable/vendor-bank-account-workflow
Type: vendor
Read in session: 0007C

Summary: D365 Finance has built-in approval for vendor bank account create and update. Per-field protection. Data-entity import can bypass, be rejected, or make proposals. New account unusable until approver approves.

Quotes:
- "This feature helps reduce the risk of fraud by detecting and preventing unapproved changes." — Microsoft Learn, intro
- "The new bank account record isn't available for use until an approver approves it." — Microsoft Learn, add new vendor bank account
- "Allow changes without approval – The data entity updates values for all fields without processing the changes through the workflow." — Microsoft Learn, Data entity behavior (update)
- "Your changes to protected fields aren't updated until an approver approves them." — Microsoft Learn, update existing bank account
- "Set this option to No to allow users to update all fields on existing bank account records without requiring approval." — Microsoft Learn, Bank account approval (update)
