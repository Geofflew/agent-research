# Use the Approval Process Channel for Human Approval Nodes in AI Agent Studio (Oracle 26C What's New)

URL: https://docs.oracle.com/en/cloud/saas/readiness/common/26c/common26c/26C-common-wn-f50152.htm
Type: vendor
Read in session: 0008C

Summary: Oracle 26C feature (added 23 JUN 2026, description updated 20 AUG 2026): approval processes (levels, approver rules, manager chains) attach to agent workflow nodes; the workflow pauses until approval. Generic, not amount- or payment-specific; no quantitative limits.

Quotes:
- "At runtime, the workflow is paused while the request is routed through the selected approval process and resumes after the required approval outcome is received." — Oracle 26C What's New
- "It allows approval requests to follow predefined approval levels, approver rules, manager chains, notification channels, and conditional routing logic." — Oracle 26C What's New
