# Oracle ARCS: Updating Reconciliations (auto-reconciliation methods, failure path)

URL: https://docs.oracle.com/en/cloud/saas/account-reconcile-cloud/adarc/admin_recons_edit_100xd76326fc.html
Type: vendor
Read in session: 0007C

Summary: Admin guide. Auto-rec failure sets status Open so preparer prepares manually; success sets Closed. Manually entered balances make a reconciliation ineligible for auto-rec.

Quotes:
- "If any conditions are false, then auto-reconciliation fails, and the reconciliation status is set to Open so that the Preparer can manually prepare the reconciliation" — Oracle docs, Oracle ARCS: Updating Reconciliations (auto-reconciliation methods, failure path)
- "When Auto-Reconciliation succeeds, the reconciliation status is set to Closed." — Oracle docs, Oracle ARCS: Updating Reconciliations (auto-reconciliation methods, failure path)
