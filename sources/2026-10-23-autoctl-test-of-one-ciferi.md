# ISAE 3402 FAQ: IT controls testing and sample sizes (Ciferi)

URL: https://ciferi.com/blog/isae-3402-faq-it-controls-testing-and-what-auditors-actually-check
Type: vendor
Read in session: 0004

Summary: Compliance-tooling vendor blog, ISAE 3402 context, practitioner convention not a standard. Manual controls sampled (daily 25). Automated control with strong ITGCs: one configuration test + no-change evidence covers whole population. Evidence = configuration plus change-management log, not outcomes.

Quotes:
- "for automated controls with strong itgcs, a single test of the configuration (plus evidence of no changes during the period) can cover the entire population because the control operated identically every time." — Ciferi
- "this is the efficiency gain from strong itgcs: it reduces the sampling burden on application controls." — Ciferi
- "inspect the system configuration (tax tables, contribution rates) and confirm no changes to the calculation logic during the period via the change management log." — Ciferi, payroll worked example
