# Internal Supplier Profile Bank Account Change (Oracle Fusion Procurement 26A)

URL: https://docs.oracle.com/en/cloud/saas/procurement/26a/oaprc/internal-supplier-profile-bank-account-change.html
Type: vendor
Read in session: 0007C

Summary: Oracle supplier bank edits are done by Supplier Administrator or Supplier Manager (procurement side), saved but not applied until change-request approval. Lists which bank changes need approval.

Quotes:
- "As a Supplier Administrator or Supplier Manager, use the Supplier page to modify bank account information." — Oracle Help Center, intro
- "Bank account changes are also saved, but not submitted for approval." — Oracle Help Center, Save vs Submit
- "Approval is required for bank account changes made at the supplier, address, or site level." — Oracle Help Center
- "Setting a bank account as the primary account" — Oracle Help Center, changes requiring approval
