# Microsoft Copilot Studio billing: Copilot Credits per agent action

URL: https://learn.microsoft.com/en-us/microsoft-copilot-studio/requirements-messages-management
Type: vendor
Read in session: 0006A

Summary: MS bills agents per Copilot Credit per action. Rate always applies per core action. No acceptance condition. M365 Copilot-licensed users: no charge.

Quotes:
- "The feature rate covers the core action the agent performs, such as generative answers, executing actions in flows, or performing agent actions. This rate always applies, regardless of the model used." — vendor page
- "When prepaid capacity is exhausted, agent flow enforcement blocks new runs rather than disabling the agent." — vendor page
