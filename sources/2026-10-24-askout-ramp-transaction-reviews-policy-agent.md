# Ramp help: reviewing transactions (Policy Agent section)

URL: https://support.ramp.com/hc/en-us/articles/4417421399699-Transaction-reviews
Type: vendor
Read in session: 0008B

Summary: Policy Agent (Plus) reads every card transaction against written policy and only recommends to a human reviewer; employees cannot see its assessments. The agent does not message the cardholder: asking for more information is the human reviewer's "Request changes", which opens an email thread.

Quotes:
- "Policy Agent recommendations are suggestions only" — Ramp Help Center
- "Review recommended – The agent is uncertain, missing context, or your policy explicitly requires human review" — Ramp Help Center
- "Employees cannot see Policy Agent assessments." — Ramp Help Center
- "Ramp will start an email thread between you and the cardholder to collect this additional information." — Ramp Help Center, Reject / Request changes
- "Any updated assessments after new information was added" — Ramp Help Center, activity feed contents
- "Ramp's transaction review process does not create a bottleneck in your reconciliation process each month." — Ramp Help Center
