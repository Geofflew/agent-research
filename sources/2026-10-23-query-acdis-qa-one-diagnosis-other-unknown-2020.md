# Q&A: Compliant query practice (single-option queries), ACDIS CDI Strategies

URL: https://www.acdis.org/articles/qa-compliant-query-practice
Type: secondary
Read in session: 0006B

Summary: Practitioner Q&A applying the 2019 brief: a query offering one clinically supported diagnosis with no alternatives is leading; adding "other, please specify" and "clinically unable to determine" is what keeps it non-leading. Quotes the brief with page numbers.

Quotes:
- "if i gave clinical indicators for sepsis on a query and only offered sepsis as a choice and did not provide any other choices at all, that would be considered leading the provider to an answer." — Q&A: Compliant query practice (single-option queries)
- "you are offering providers a choice to freely write whatever they wish in their response without leading them to any specific answer." — Q&A: Compliant query practice (single-option queries)
- "it is more important that a query demonstrate the appropriate clinical indicators and correctly identify possible choices rather than the number of choices that are listed" — Q&A: Compliant query practice (single-option queries)
