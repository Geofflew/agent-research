Summary: SAP training lesson. Joule agents act with the user's identity and permissions (delegated, no separate agent identity stated). AI Agent Hub lifecycle: discover/provision, build (goals, permissions, triggers), observe, secure/govern, decommission with audit history kept. Agents do expense approval, PO creation; no journal-entry posting or per-decision-class scoping stated; availability mixes GA, early access, planned.

Quotes:
- "every agent action carries your identity and access permissions, so agents can only act on what you are entitled to act on" — SAP Learning, Getting to know Joule agents
- "apply identity and access controls, verify agents and mcp servers, enforce compliance policies, and maintain audit trails across all agent activity" — SAP Learning, AI Agent Hub secure and govern stage
- "retire agents that are no longer needed, with full audit history preserved" — SAP Learning, AI Agent Hub optimize and decommission stage
- "define the agent's goals, permissions, triggers, and workflows" — SAP Learning, AI Agent Hub plan and build stage
