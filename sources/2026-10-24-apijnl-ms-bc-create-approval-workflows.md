# Create approval workflows to connect tasks (Business Central)

URL: https://learn.microsoft.com/en-us/dynamics365/business-central/across-how-to-create-workflows
Type: vendor
Read in session: 0007A

Summary: Generic Business Central workflow page. Workflows can include system tasks such as automatic posting; triggers include "a journal line is created". Approval is a workflow step that a user starts on the record. The page and the Journals API page (dynamics_journalline) do not state whether API-created journal lines or API posting are subject to approval: docs are silent.

Quotes:
- "You can include system tasks, such as automatic posting, as steps in workflows that user tasks precede or follow." — Microsoft Learn, Business Central
- "Requesting and granting approval to create new records are typical workflow steps." — Microsoft Learn, Business Central
- "a journal line is created" — Microsoft Learn, Business Central (example workflow trigger)
