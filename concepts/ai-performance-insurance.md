# AI performance insurance

Definition: Affirmative insurance paying when an AI model's measured accuracy/error rate drifts past agreed baseline (parametric-like trigger), vs AI exclusions in standard lines.

Related concepts: [[validation-harness]], [[statistical-validation-of-automated-review]], [[automation-bias]]

Evidence:
- aiSure: quantitative I/O analysis + historical performance -> price; pays when error rate drifts past threshold [ins-munichre-aisure-faq], [ins-munichre-aisure-page].
- Armilla/Lloyd's: pays on degradation 95% -> 85%, not single error; limits to $25m Jan 2026 [ins-armilla-lloyds-ft].
- iTOO: agree accuracy rate / error threshold first; e.g. 98% fraud detection [ins-itoo-aisure-moonstone].
- AIG, WR Berkley AI exclusions; fear correlated agent losses [ins-insurers-exclude-ai-beinsure].
- CPA firm E&O: no AI claims yet; underwriters ask policy/protocol questions only [ins-cpa-firms-ai-underwriting-dig-in].

Thesis: C15 — insurer backing vendor accuracy warranty = first outside party accepting measured agent error rate, before auditor.

C15 (0005C): insurer baseline forces per-class blind-sample measurement into product; questionnaire underwriting cannot see correlated class failure.
