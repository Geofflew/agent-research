# What does the controller do on the day a standard's executable rule set takes effect?

Status: live
Opened: session 0008C
Yield: 0.0
Touches: C14, C26, C38; scenarios/2036-standard-setter-ships-the-rule-as-code; threads/settings-change-screen
Sources: [expq4-ifrs-taxonomy-2025-remains-current-2026]

What we know so far: Standard setters already ship one machine-readable artefact on a release calendar, the tagging taxonomy, and can skip a year. The IFRS Foundation told stakeholders to "continue using the ifrs accounting taxonomy 2025" and that "the next annual ifrs accounting taxonomy will be published in the first quarter of 2027" [expq4-ifrs-taxonomy-2025-remains-current-2026] (primary). That is a release cadence for presentation tags, not recognition rules; the 2036 scenario extends it to rules that change every company's frozen rule on one date, which C26 says restarts the evidence at all of them at once.

What it would take to become a claim: any setter or regulator publishing executable recognition or measurement rules (rules-as-code pilots, tax authority fact graphs), with an effective-date process.

Open sub-questions:
- Would companies parallel-run the reference rule against their own for a quarter, and who reads the differences?
- Does a departure from the reference rule become a disclosure?
