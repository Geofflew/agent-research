# Is a blind check by one AI model independent of the model it checks, if both come from the same family?

Status: live
Opened: session 0001F
Yield: 0.0
Touches: C12, C25, C26, C38; scenarios/2036-auditor-and-client-must-use-different-models, scenarios/2031-auditor-agent-re-prepares-the-close
Sources: [corrmodel-kim-correlated-errors-llms], [corrmodel-goel-great-models-think-alike], [corrmodel-panickssery-self-preference], [dissim-airbus-fbw-total-dependability]

What we know so far: across more than 350 language models, on one leaderboard dataset models agree 60 percent of the time when both are wrong, and shared provider and architecture drive the correlation, though the largest models correlate even across providers [corrmodel-kim-correlated-errors-llms]. Model mistakes are becoming more similar as capabilities rise, and models used as judges score models similar to themselves more favorably [corrmodel-goel-great-models-think-alike]; a model judging its own outputs rates them above what people rate them [corrmodel-panickssery-self-preference]. Safety-critical aviation already answers the same problem by design: Airbus built its primary and secondary flight computers with different processors, tools, teams, and specifications, and reports that in-service events justified the dissimilarity [dissim-airbus-fbw-total-dependability]. C12 says a usable error rate needs a sample prepared blind to the agent's draft; these sources say blindness to the draft is not enough when the blind preparer is a sibling model, because the two make the same mistake independently.

What it would take to become a claim: one finance or accounting case (or a benchmark on accounting tasks) where two models of the same family agree on the same wrong treatment, or an audit firm or regulator stating that the auditor's tools must differ from the client's. With that, B can add a claim qualifying C12 for model-prepared blind samples and the auditor re-preparation route.

Open sub-questions:
- Do the large audit firms' agents run on the same model providers as the leading close vendors' agents?
- Does correlation hold on structured accounting judgments (revenue cut-off, lease classification) as strongly as on leaderboard questions?
- Would a human blind sample remain necessary even when the re-preparing agent is from a different family?

Finding: the shared-provider risk C49 describes is live now, not hypothetical: three of the Big Four have Anthropic alliances and the largest small-business ledger vendor builds agents on Claude, so an auditor's agent and a client's agent on the same provider is a plausible pair in 2027. But firms are multi-provider (KPMG, Intuit, EY catalog), so which model ran a given audit procedure is a configuration fact, which supports C49's consequence (the auditor asks which model at planning) more than the different-models scenario's family rule.
