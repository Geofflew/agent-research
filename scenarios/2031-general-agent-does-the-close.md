# By 2031 a general-purpose agent from a model provider, connected to the ERP through its protocol server, does most of the close at small and mid-sized companies, and close software vendors survive only as publishers of procedure skills sold through the model provider's marketplace

Year: 2031

Depends on:
- C10 (for ordinary journals the kill switch is the period status, and since C2 merged into it in 0007A, ERP protocol servers scope an outside agent by role and record type rather than amount or period): the general agent reaches the ledger through exactly that role-and-record-type connection; if ERPs closed their protocol servers to outside agents, only ERP-native agents could do the work.

- C33 (the close checklist survives as the control record, the agent signs the preparer's line, and the controller checks the output it attached): the checklist and its sign-offs are what the general agent produces, so no close platform is needed to hold them; if sign-offs required a close platform's record, the vendor would keep the control record.

In 2031 the finance team at a $60 million software company does not log into a close platform. Its accountant and controller work with the same general-purpose agent the rest of the company uses, which reaches the ERP, the bank portal, the billing system, and the spend tool through their protocol servers. For the close it loads a set of skills: a revenue recognition skill, a prepaid and accrual skill, a reconciliation skill, and a flux commentary skill, each a written procedure with scripts, bought from what used to be close software companies through the model provider's marketplace. The agent prepares each task, attaches its work to the checklist in a shared folder, signs the preparer line, and asks the controller for anything it cannot finish. The company pays the model provider for usage and the skill publishers per skill per entity. Close software vendors that had sold seats and modules now compete on the quality of their written procedures and test data, the way tax software companies once competed on their rule tables.

Mechanism: The small-company ERPs have already opened their ledgers to outside agents unevenly. Intuit's protocol server for QuickBooks Online offers create, update, and delete on 29 entity types including journal entries, Business Central's lets an administrator allow outside agents to create records and run actions such as posting documents, NetSuite's lets a role create and update records, and Sage Intacct's is read-only, so an outside agent cannot post at all (C10). On the open ERPs an agent can be provisioned as a human role with payee fields and payment release denied (C23). Model providers sold packaged skills that bundle a procedure with scripts from late 2025, and companies already pay for a general agent across departments. Once the general agent can sign the checklist line with its output attached (C33), the close platform's remaining jobs are holding the checklist and the procedures, which a shared folder and a skill file can do. Mid-market companies leaving SAP's old ERP before its mainstream maintenance ends in 2027, and those replacing other systems at the usual seven-to-ten-year cycle, start treating protocol write access as a selection criterion, so by 2031 the general-agent close is common on the open ERPs and rare on the closed ones. Close vendors, losing seats on the open ERPs, turn their procedure libraries into skills, while audited enterprises stay on platforms because auditors discount the general agent's work (C25).

The controller stops administering a close platform and starts choosing and testing skills, approving each new version before it runs on the books, and reviewing the agent's checklist sign-offs and questions. The accountant stops preparing and works the agent's questions and exceptions. The close software company's product manager stops building screens and writes procedures, test cases, and scripts. The ERP vendor with a read-only protocol server keeps its close inside its own agents and platforms, and loses mid-market deals to open ledgers. The lender reading the package sees the same output as before and does not ask which software produced it.

What would settle it: a company running its month-end close with a general agent and purchased skills, with no close platform; a close vendor selling its procedures as skills for an outside agent; an ERP protocol server whose tool list covers journal posting and reconciliation for outside agents.

Signposts: a close vendor publishes a skill package for an outside agent by 2028; mid-market ERP replacements between 2027 and 2030 that list protocol-server openness as a selection criterion; failing signpost, ERPs restrict write tools on protocol servers to their own agents before 2029, which would keep the close inside ERP-native agents or platforms.
