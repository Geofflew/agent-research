# By 2036 the accounting standard-setters publish each new standard's recognition and measurement rules as an executable reference rule set alongside the text, so a standard's effective date becomes a software release that changes every company's close agent on the same day, and disputes with the auditor move from what the standard means to whether the company departed from the reference rule

Year: 2036
Status: live
Contradicts: 2036-close-layer-owns-the-ledger. There each company's close platform holds its accounting policies as versioned clauses it writes and tests itself; here the clauses for every new standard arrive from the standard-setter as a reference rule set, so the close layer holds only the company's departures from it.
Depends on:
- C26 (the auditor benchmarks frozen rules, and every change to a rule or threshold restarts the evidence): a reference rule set is a frozen rule the auditor can benchmark once for all companies, and when it takes effect every company's rule changes at once, which is why setters schedule effective dates as releases with a parallel-run period; if auditors could rely on a model's judgment directly, or rule changes did not restart the evidence, no one would need the rules published or the switch planned.
- C38 (a model change on the provider's schedule lands on every customer's controls at once): the standard-setter learns from the provider retirements of the late 2020s that a change landing on all companies the same day needs advance notice, a test period, and a fixed date; if those retirements had passed without control failures, setters would have no reason to copy release practice.
Clocks: IFRS 18, the new presentation standard, takes effect for annual periods beginning on 1 January 2027, the first major standard adopted after close agents are in use; the FASB and IASB already publish machine-readable taxonomies each year for tagging filed statements, so the setters already run an annual release; European securities regulators publish common enforcement priorities each autumn for the coming year-end, so inconsistent application of IFRS 18 in 2027 statements can be flagged in the 2028 priorities; standards typically allow two to three years between issue and effective date, so a standard issued in 2033 with a reference rule set takes effect on 1 January 2036, the first to arrive as code.
Yield: 0.0

In 2036 a new lease-modification standard takes effect, and with it the setter's reference rule set: the conditions, the remeasurement steps, and the test cases that define a correct answer. Every close vendor loads the same rule set in the parallel-run quarter, the company's agent runs old and new side by side, and the controller signs the switch on the effective date. Where the company believes its facts call for a different treatment, it records a departure with its reasoning, and the auditor's review concentrates on the departures list rather than on the whole class.

Mechanism: In 2027 statements, vendors' agents apply IFRS 18 in different ways, and companies with the same facts present different subtotals because their vendors read a paragraph differently. European enforcers flag the inconsistency in their 2028 priorities, which puts it on the setters' post-implementation agenda. Benchmarking needs a frozen rule and every rule change restarts the evidence (C26), so auditors and vendors ask the setters for one authoritative reading instead of many private encodings. The setters already ship annual taxonomies, and the provider retirements of the late 2020s showed what a change landing everywhere at once does to controls (C38), so they adopt release practice: a rule set with test cases, a parallel-run quarter, and a fixed date. The first standard issued that way, in 2033, takes effect on 1 January 2036.

In the 2036 parallel-run quarter the controller stops writing an implementation memo and decides, contract by contract, whether to accept the reference outcome or record a departure, knowing each departure will be the auditor's first question. The auditor stops testing each client's implementation and samples the departures list, challenging any departure the facts do not support. The setter's staff answer test-case questions from vendors the way a software team answers bug reports. The close vendor's product team stops interpreting standards and ships the rule set on the setter's date.

What would settle it: a standard-setter publishing executable examples or test cases with a standard; a vendor or audit firm reporting divergent agent implementations of IFRS 18.

Signposts: by 2029 an audit regulator or firm reports inconsistent automated application of a new standard across clients; failing signpost, by 2033 setters still publish only text and taxonomies, and vendors' encodings stay private.
