# By 2036 the audit committee of a listed company runs its own agent over the ledger, reporting to the directors rather than to management, so the external auditor tests the board's agent instead of running its own and the CFO's numbers meet a machine reviewer that management does not control

Year: 2036
Status: live
Contradicts: C46, which has the external auditor answer the client's agent with its own full-population agent. Here, by 2036, the auditor stops running its own population agent over routine classes at listed clients and relies on the audit committee's, because that agent is configured by the directors and is independent of the management whose agents prepared the entries; the two exception lists of C46 collapse into one that the board owns.
Depends on:
- C46 (the auditor answers the client's agent with its own full-population agent, because the client's agent's logic can change and cannot be re-performed): the board copies the auditor's method first, and the auditor's later reliance is on an agent built to its own template; if auditors had relied on management's agents from the start, directors would have had no model to copy and no reason to.
- C49 (two agents agreeing is not evidence, because model errors correlate across providers): the board's agent reports where it agrees with management's agents as well as where it differs, and the external auditor samples the agreed entries; if agreement counted, the board's list of differences would be all anyone read.
- C51 (a usable error rate comes only from a blind sample, drawn from the items the agent marks confident, where errors that survive review sit): the board's agent re-prepares a sample blind each quarter, which gives directors an error rate measured outside management's reach; if ordinary review produced a usable rate, management's own figure would do.

In 2036 a listed company's internal audit function runs an agent that the audit committee, not the CFO, approves and configures. Each night the agent reads every journal and the settings register of every management agent, re-prepares a blind sample each quarter, and sends the committee chair a list of entries it would have treated differently. The external auditor reads that list, tests how the board's agent is configured and who can change it, and runs its own agent only over journal entries and management override, the high-judgment work it may not hand to internal audit. The CFO's team answers the board's agent's queries before the auditor's, and a management change to an agent's settings shows up in the chair's report the next morning.

Mechanism: Auditors run their own agents over the whole population because they cannot re-perform the client's (C46), and two agents agreeing proves nothing on its own (C49). Internal audit, which already reports functionally to the board under the 2025 standards, copies the auditor's method: a population agent with a blind sample (C51), its configuration approved by the audit committee. After the first agent-caused misstatements, under Delaware's 2019 Marchand duty to oversee a mission-critical risk, committees make that agent a charter item. The external auditor then uses its output the way AS 2605 and ISA 610 already allow it to use internal audit's work, after testing the function's objectivity and the agent's configuration, so it stops duplicating the population run for routine classes and the audit fee falls.

The audit committee chair stops reading the auditor's year-end summary as the first sign of trouble and reads the agent's weekly list. The CFO answers the board agent's disagreements. The audit partner's fieldwork becomes testing one agent's independence and configuration rather than reconciling two lists.

What would settle it: an audit committee charter or proxy statement naming technology the committee itself commissions over the ledger; an auditor's methodology describing reliance on a board-commissioned agent.

Signposts: by 2030 a proxy statement discloses an audit-committee-commissioned analytics or agent review of the ledger; failing signpost, through 2034 audit firms keep running their own population agents at listed clients and committees buy nothing of their own.
