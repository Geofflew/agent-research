# By 2031 auditors and lenders rely on the close vendor's attested error rate per task class the way they rely on a payroll processor's controls report, so mid-market companies buy an assured close and stop configuring their own

Year: 2031
Status: live
Contradicts: 2031-lender-reads-the-authority-record (here the outsider relies on how the close was prepared, not on a record the tax authority holds) and 2031-crime-insurer-licenses-the-payables-agent (there the first outside acceptor is an insurer pricing manipulation, here an auditor relying on a measured error rate).
Depends on:
- C51 (a usable error rate comes only from a blind sample, drawn from the items the agent marks confident, where errors that survive review sit): if ordinary review logs gave a usable rate, nobody would pay a vendor to measure one.
- C46 (the auditor answers the client's agent with its own population agent and discounts agent-prepared evidence, so testing rises first): if auditors relied on each client's agent directly, nobody would buy the vendor's report.
- C26 (unreviewed work arrives only as frozen rules the auditor benchmarks, or a threshold checked by a sample above it): the vendor's report is that sample, run through the existing benchmarking route; if auditors waited for a new standard, nothing below happens before the late 2030s.
- C28 (pricing per reviewer-accepted task, with the blind sample outside the billing unit and refunds following its disagreement rate): the refund here follows the attested rate, not rejections; if billing and the sample were one event, the rate would measure agreement and be worthless to an auditor.
- C42 (the audit fee falls only where the agent runs one model version across two audited years, so vendors run fee-bearing controls on open weights they host): the attested rate holds only for the model it was measured on, so the vendor freezes one self-hosted model per report period; if hosted versions outlived an audit cycle, nothing would need freezing and companies could tune freely.
- C11 (agent monitoring lowers the external audit budget only for companies with a clean prior-year control opinion): the vendor's report gives a customer that route on its first year, because the clean opinion belongs to the vendor's control, not the customer's; if auditors required each customer's own clean history, the report would buy nothing in year one.
Clocks: the US technology-assisted analysis amendments apply to fiscal years beginning on or after 15 December 2025; the revised international audit evidence standard governs audits from about mid-2029; a service-organization report covers about twelve months, so a vendor measuring from 2028 reports in 2029; hosted model versions live about twelve to sixteen months, under two audit cycles.
Yield: 0.0

In 2031 a US company with $300 million of revenue buys its routine close the way it has bought payroll for forty years. Reconciliations, amortization, intercompany matching, and standard accruals run on the vendor's agents under its standard configuration, and the vendor holds a service-organization report testing, over twelve months, the per-class error rate measured by blind re-preparation of a sample drawn, across all its customers, from the items its agents marked confident. The auditor tests only the controls the report says the customer must operate and does not sample the routine classes. A customer that changes a setting outside the standard loses coverage for that class until the next period, so the vendor sells conformity as much as software, with a refund when the attested rate exceeds the tolerable rate.

Mechanism: Auditors already discount evidence from AI systems (C46) and charge for it in the 2027 and 2028 audits. One company cannot afford a blind sample for twenty task classes, but a vendor with 2,000 customers (illustrative) can draw one across all of them (C51). The vendor commissions a service-organization report with the blind sample as a control, and auditors rely on it through the route that already exists (C26). Because the rate holds only for the model it was measured on, the vendor moves its fee-bearing classes to an open-weight model it hosts and keeps fixed for each report period, and customers who want coverage stop changing settings (C42).

The controller stops tuning thresholds, approves the vendor's model change once between reports, and decides which classes to carve out and own with the company's own sample. The auditor stops sampling routine classes and spends the hours on estimates and carved-out classes, so the routine fee falls while the judgment fee rises.

What would settle it: a vendor's service-organization report that scopes an agent component and names the model version it covers; an audit firm relying on one for reconciliations.

Signposts: a close vendor's report covers an agent feature for a period ending in 2028 or 2029; failing signpost, by the end of 2030 no vendor report scopes agent error rates and auditors still sample agent-prepared reconciliations at each customer.
