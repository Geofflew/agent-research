# By 2031 the crime insurer, not the auditor or the ERP, decides whether a payables agent may act on a changed bank account, because social engineering cover pays only if an employee verified the instruction, and carriers rewrite that clause to admit an agent only with a yearly agent certification and a bank name match

Year: 2031
Status: live
Contradicts: 2031-close-vendor-is-the-audited-party. There the first outsider to accept agent work relies on the vendor's attested error rate; here it is the insurer, which prices manipulation rather than error through a policy endorsement.
Depends on:
- C23 (the hard limit on agent write authority is adversarial input, so payee bank details and payment release are carved out of the agent's role): the insurer prices exactly that manipulation loss; if error rather than manipulation were the binding risk, the crime insurer would have nothing distinct to price and the auditor would lead.
- C40 (agents are first allowed to enter new payee accounts where a register shows who owns the account): the rewritten clause accepts that register or a bank name match in place of a person's callback; if no outside name check existed, the insurer would have no substitute for the employee and would exclude agents.
- C10 (hard limits belong at payment release and period lock): the endorsement attaches at payment release; if ERPs limited every journal, the insurer's condition would be one control among many.
- C46 (external auditors discount agent-prepared evidence and run their own population agent): this is why no audit route opens first; if auditors relied on agent work early, the audit route would set agent authority before the insurer.
Clocks: carriers' social engineering endorsements already make cover conditional on an employee verifying a transfer instruction by callback and documenting it (Intact's form M350, 03-20); ISO's generative AI exclusion for general liability became available in January 2026; the AIUC-1 agent certification is valid for one year; EU verification of payee became mandatory on 9 October 2025; crime policies renew annually, so a rewritten clause reaches every insured within one renewal.
Yield: 0.0

In March 2031 a $400 million distributor's controller learns what the payables agent may do at the crime insurance renewal, not at audit planning (illustrative figures). The carrier accepts an agent's verification of a changed vendor account in place of an employee's callback if the agent holds a current certification and the account passed the bank's name check, and the close vendor ships that configuration as a setting per carrier's form. Insurance writes the rule for a new kind of actor before any regulator does.

Mechanism: The callback clause names an employee as verifier, so an agent that changes a vendor account, or pays to a changed one, would void the cover, and from 2026 companies carve payee changes out of the agent's role (C23) for an insurance reason before any auditor asks. At the 2027 and 2028 renewals carriers that excluded AI from liability lines in 2026 must choose on crime cover: exclude agents and lose premium to carriers that do not, or rewrite the verifier clause. They rewrite it with checks an underwriter can confirm yearly: an agent certification and a name or register match (C40). By 2030 the endorsement is the first outside rule on agent payments, because it attaches at payment release (C10) while auditors still discount agent evidence (C46).

The controller decides agent scope at renewal, trading a lower social engineering sublimit for letting the agent verify name-matched changes. The payables manager stops calling back every vendor bank change, calls back only those without a name match, and keeps the log a claim requires. The auditor tests the insurer's conditions as an entity-level control.

What would settle it: a crime carrier's endorsement or application naming AI agents; a denied claim where an agent verified the change.

Signposts: by the 2028 renewals a crime carrier's application asks whether an agent can change vendor bank details; failing signpost, carriers extend absolute AI exclusions to crime cover by 2029.
